# ICP: Medicina Estética / Dermatología

Perfil inicial:

- Médico privado en México.
- Consulta de procedimientos o seguimiento frecuente.
- Usa Word, Excel, Drive, WhatsApp o papel para documentar.
- Tiene dolor por consentimientos, recetas, fotos, seguimiento y reclamaciones.
- Valora setup asistido y soporte directo.

Dolores probables:

- Consentimientos improvisados.
- Recetas sin evidencia verificable.
- Expedientes dispersos.
- Dificultad para demostrar qué se documentó y cuándo.
- Tiempo perdido entre consulta, WhatsApp y documentos.

Mensaje principal:

CloudMedRecord ayuda a crear expedientes, notas, recetas y consentimientos con firma digital, hash, bitácora y QR verificable.
