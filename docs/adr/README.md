# Architecture Decision Records

Decisiones arquitectónicas significativas y su justificación. Una ADR se escribe cuando una
decisión cambia la forma del sistema, retira un componente, o fija una estrategia que un
lector futuro podría cuestionar.

Formato: contexto → decisión → consecuencias → alternativas. Las ADR son inmutables una vez
aceptadas; un cambio de rumbo se registra en una ADR nueva que supersede a la anterior.
